## Publish with GitHub Pages

1. Create a new public repository named `emmanuelnebo.github.io` (this gives the site the address `https://emmanuelnebo.github.io/`).
2. Upload the **contents** of this folder to the root of that repository. `index.html` must be at the repository root, not inside another nested folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL should be `https://emmanuelnebo.github.io/`.

If you prefer to use an existing repository name instead, the published URL will normally be `https://emmanuelnebo.github.io/REPOSITORY-NAME/`.

## Before publishing — two small items to confirm

- Replace the generic LinkedIn URL in `index.html` with your exact LinkedIn profile URL.
- The First Power BI project uses the Sales Performance & Profitability dashboard image. The LogiTrack Fleet Performance Capstone uses the supplied LogiTrack dashboard image.

## Local preview

Open `index.html` in a browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

All image files are in `assets/images/`. Keep the folder structure intact when uploading.
